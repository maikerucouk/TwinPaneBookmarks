# Twin Pane Bookmarks

Twin Pane Bookmarks is a Chrome Manifest V3 extension for managing bookmarks in two independent panes. The active pane acts as the source, and the other pane acts as the destination. Users can navigate folders, select one or multiple items, and copy, move, rename, edit, duplicate, or delete bookmarks and folders.

The extension also supports bookmark previews, persistent folder sorting, Netscape HTML bookmark import/export, and keyboard shortcuts for common operations. Bookmark data is managed through Chrome's bookmarks API.

GitHub source code: [TwinPaneBookmarks](https://github.com/maikerucouk/TwinPaneBookmarks)
